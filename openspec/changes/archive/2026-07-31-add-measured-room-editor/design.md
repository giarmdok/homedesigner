## Approach
Build geometry commands over the canonical model and render them through the foundation adapter. Store photo metadata/reference separately from geometry. Use explicit unit conversion and a scale calibration workflow before editing.
## Non-goals
No automatic detection, multi-room projects, furniture, 3D, cloud storage, or AI.
## Acceptance
A user can create exactly one Master Bedroom, enter dimensions, add/edit/delete walls and openings, upload/view a measured photo reference, calibrate scale, and receive blocking errors for invalid units or geometry.
