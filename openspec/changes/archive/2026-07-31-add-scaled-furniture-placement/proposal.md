## Why
Once a measured plan exists, homeowners need to evaluate real furniture at true scale and understand fit before committing to a layout.
## What Changes
- Add furniture catalog/manual creation, image references, dimensions, placement, selection, rotation, proportional resize, colors/materials, collision/fit feedback, and 2D manipulation.
## Capabilities
### New Capabilities
- `scaled-furniture-placement`: Measured 2D furniture workflow.
### Modified Capabilities
- `measured-room-editor`: Add furniture to the editable canonical plan.
## Impact
Furniture entities, catalog/assets, 2D interaction tools, and spatial validation.
## Dependencies and order
Requires changes 1–2; precedes persistence and 3D.
