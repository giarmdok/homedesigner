## Why
The repository has no application scaffold or shared contract. A browser-first foundation is needed before editor features can be delivered consistently.
## What Changes
- Establish a TypeScript, React, Vite PC-browser stack with a 2D canvas/editor library; reserve Three.js/react-three-fiber for the later 3D phase.
- Create an app shell/domain boundaries and a canonical, unit-aware room/furniture model.
## Capabilities
### New Capabilities
- `room-designer-foundation`: Application architecture and canonical model.
### Modified Capabilities
- None.
## Impact
Initial tooling, source structure, domain types, validation conventions, and developer documentation.
