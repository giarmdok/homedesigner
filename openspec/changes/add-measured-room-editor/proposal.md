## Why
Users need a trustworthy measured Master Bedroom plan before placing furniture. Manual editing must remain usable while automated detection is deferred.
## What Changes
- Add one Master Bedroom project flow, dimensions, walls, doors, windows, measured-photo upload, editable 2D plan, and scale/unit validation.
## Capabilities
### New Capabilities
- `measured-room-editor`: Manual measured room planning.
### Modified Capabilities
- `room-designer-foundation`: Extend the canonical model with editable room geometry and references.
## Impact
2D editor UI, geometry commands, asset references, and validation feedback.
## Dependencies and order
Requires `establish-room-designer-foundation`; precedes furniture placement.
